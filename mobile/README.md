# VetPro móvil

Aplicación React Native con Expo. La configuración, las herramientas utilizadas y las decisiones de la cursada están documentadas en el [README principal](../README.md).

Desde esta carpeta: `npm install` y `npx expo start`. Para un teléfono físico, configurar `EXPO_PUBLIC_API_URL` en `.env` con la dirección de la computadora donde se ejecuta la API.

Las mascotas, sedes, turnos y notificaciones se consultan en el backend. Las fotos elegidas se guardan como datos Base64 en SQLite. No hay registros de muestra cargados desde la interfaz.
